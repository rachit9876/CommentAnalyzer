# CommentAnalyzer

**CommentAnalyzer** is a simple Streamlit app that analyzes comments from **YouTube** and **Twitter**, visualizing sentiment, engagement, and more using beautiful plots and emojis.

## 🚀 Quickstart

Open your terminal and follow these steps:

```bash
cd C:\
mkdir CommentAnalyzer && cd CommentAnalyzer
```

### 1. Create a Virtual Environment (optional but recommended)

```bash
python -m venv venv
```

Activate it:

- **Windows**:

    ```bash
    venv\Scripts\activate
    ```

- **macOS/Linux**:

    ```bash
    source venv/bin/activate
    ```

### 2. Install Requirements

```bash
pip install -r requirements.txt
```

### 3. Run the App

```bash
streamlit run app.py
```
