# CommentAnalyzer

**CommentAnalyzer** is a simple and interactive **Streamlit** app that analyzes comments from **YouTube** and **Twitter**, visualizing sentiment, engagement, and more using beautiful plots and emojis.

---

## 🚀 Quickstart

Open your terminal or command prompt and paste all of them one by one:

```bash
cd C:\
mkdir CommentAnalyzer && cd CommentAnalyzer
```

---

### 1. Create a Virtual Environment (optional but recommended)

```bash
python -m venv venv
```

#### After creation, activate it:

- **Windows**:

    ```bash
    venv\Scripts\activate
    ```

- **macOS/Linux**:

    ```bash
    source venv/bin/activate
    ```

---

### 2. Download the Required Files

Download and place the following files in your `CommentAnalyzer` folder:

- `app.py`
- `positive_keywords.csv`
- `negative_keywords.csv`
- `requirements.txt`

Your folder should look like this:

```bash
C:\CommentAnalyzer
│
├── venv/                    # Virtual environment folder
├── comments_data.csv        # Will be generated by the app
├── positive_keywords.csv    # CSV with positive keywords (e.g., "happy", "great")
├── negative_keywords.csv    # CSV with negative keywords (e.g., "sad", "bad")
├── app.py                   # Main Streamlit app file
└── requirements.txt         # Dependency list
```

---

### 3. Install the Dependencies

Run the following command to install all required packages:

```bash
pip install -r requirements.txt
```

---

### 4. Run the App 🚀

Launch the app using:

```bash
streamlit run app.py
```
